Goal of the game

Answer 15 questions of increasing difficulty correctly to climb the prize ladder, all the way to the top prize.

How it works

  • Each question has 4 answers (A, B, C, D); only one is correct.
  • A correct answer moves you up one step on the prize ladder.
  • A wrong answer ends the game: you leave with the amount from the last guaranteed milestone you reached.
  • Two milestones are guaranteed: clearing them locks in that amount, even if you get a later question wrong.

Lifelines

  • 50:50 — removes two wrong answers.
  • Ask the Audience — shows how the audience voted.
  • Phone a Friend — a friend gives you their best guess.
  • Swap the Question — replaces the question with another one at the same level.

Each lifeline can only be used once per game.

Timer

The timer is optional (toggle it from the start screen): if enabled, you run out of time if you don't lock in an answer fast enough.
